# 🧪 PromptLab

> **PromptLab** é uma aplicação desenvolvida para centralizar, organizar e gerenciar prompts de inteligência artificial de forma eficiente, armazenando tudo de maneira estruturada em uma base de dados relacional.

---

## 🚀 Status do Projeto

⚠️ **Fase Atual: Estruturação do Back-End e Base de Dados (MVP - Parte 1)**  
Esta é a primeira etapa do projeto, focada na modelagem lógica do banco de dados relacional e na conexão inicial com o MySQL utilizando Python. 

---

## 🛠️ Tecnologias e Ferramentas Utilizadas

Atualmente, o projeto conta com a seguinte stack na sua base:
* **Python** (Linguagem principal para lógica e conexões)
* **MySQL** (Banco de dados relacional para persistência dos prompts)
* **Git & GitHub** (Controle de versão)
